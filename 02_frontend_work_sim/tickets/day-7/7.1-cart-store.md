# 7.1 — Move the cart into a Zustand store

**Labels:** refactor, global-state, zustand, day-7

## Branch
Before starting, create your branch:
```
git checkout -b cart-store
```

## Description
Passing the cart through props into every page and card is getting messy. Move it into a global store with **Zustand** so any component can read or update it directly.

```
npm i zustand
```

## Mock
No visual change. This is a refactor; the app should look and behave exactly like your Day 6 mocks.

## Acceptance Criteria
- [ ] `src/store/cartStore.ts` creates a typed store with `items: CartItem[]`
- [ ] Store actions: `addToCart(product)`, `increase(id)`, `decrease(id)`, `removeFromCart(id)`, `clearCart()`
- [ ] The "can't exceed stock" rule from 4.1 lives inside `addToCart` / `increase`
- [ ] `ProductCard`, `ProductDetailPage`, `CartPage` and `Navbar` read the cart from the store — **no cart props anywhere**
- [ ] Cart state and its handlers are deleted from `App.tsx`
- [ ] Everything that worked before still works

## Hints
```ts
import { create } from "zustand";

type CartState = { items: CartItem[]; addToCart: (product: Product) => void; /* ... */ };

export const useCartStore = create<CartState>((set) => ({
  items: [],
  addToCart: (product) => set((state) => ({ /* return the new items */ })),
}));
```
Select only what you need in a component: `const items = useCartStore((s) => s.items);`
