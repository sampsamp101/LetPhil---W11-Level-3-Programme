# 5.1 — Fetch products from the API

**Labels:** feature, useEffect, fetch, day-5

## Branch
Before starting, create your branch:
```
git checkout -b fetch-products
```

## Description
Real stores don't keep their products in a file. Swap out the local `src/data/products.ts` import for a real API call to **DummyJSON**:

```
GET https://dummyjson.com/products
```

Open that URL in your browser first. The response is `{ products: [...], total, skip, limit }` — the products are **inside** the `products` key. Because the local file has the same shape, none of your components should need to change.

## Mock
No visual change. The page should look exactly like your Day 4 mocks, but the data now comes from the API (check the Network tab in DevTools).

## Acceptance Criteria
- [ ] Products are stored in state in `App` (`useState<Product[]>([])`)
- [ ] A `useEffect` with an empty dependency array fetches from `https://dummyjson.com/products` once on page load
- [ ] The response is typed — create a `ProductsResponse` type for `{ products: Product[]; total: number; skip: number; limit: number }`
- [ ] `App.tsx` no longer imports from `src/data/products.ts`
- [ ] Every Day 1–4 feature (sections, stats, search, favorites, cart) still works with the fetched data
